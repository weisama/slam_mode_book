# v3.0 通信协议

## 参数ID定义表

参数ID、取值和单位供上位机与STM32共同使用。保存前按设备和场景核对；修改需要重启生效的参数后，重启并读回确认。

| 参数ID | 参数名称 | 值范围 | 说明 |
| --- | --- | --- | --- |
| 0x00 | 雷达型号 | - | 0=MID360, 1=MID360s, 2=MID360L, 10=N10, 11=N10_P， 12=M10, 13=M10p (12/13 为占位)，默认0 |
| 0x01~0x06 | 雷达安装位置 |  | 雷达相对于机器人中心的位置 = 安装位姿 T：**`base_link -> laser_link`** |
| 0x01 | X坐标 | -100~100 | 雷达位置X坐标值，单位厘米，默认0 |
| 0x02 | Y坐标 | -100~100 | 雷达位置Y坐标值，单位厘米，默认0 |
| 0x03 | Z坐标 | -100~100 | 雷达位置Z坐标值，单位厘米，默认0 |
| 0x04 | Roll角度 | -180~180 | 雷达滚转角，单位度，默认0 |
| 0x05 | Pitch角度 | -180~180 | 雷达俯仰角，单位度，默认0 |
| 0x06 | Yaw角度 | -180~180 | 雷达偏航角，单位度，默认0 |
| 0x11 | 使能与PX4通信 | 0-1 | 1=使能，模块可与PX4通信，作为位置传感器/执行路径规划，默认1 |
| 0x12 | 使能与主控通信 | 0-1 | 1=使能，模块可与主控串口通信，输出坐标/输出控制点/输入目标点，默认1 |
| **0x13** | **模式** | **0-1** | 0=建图、1=定位，默认0。定位模式需要建图模式下保存的地图 |
| **0x14** | **导航使能** | **0-1** | 1=使能，启用导航功能，**默认0** |
| **0x15** | **过滤半径** | **0~1000** | 设置过滤点云的半径大小，例如过滤机器人自身结构，单位cm，默认10。**圆心 = 机器人中心** |
| 0x21~0x29 | 路径规划与小车模型参数 | 0~1000 | 首次使用应断开电机供电，查看规划结果无误 |
| 0x21 | 最大移动速度 | 0~1000 | 规划轨迹的最大速度，单位cm/s，默认100。 |
| 0x22 | 最大加速度 | 0~1000 | 规划轨迹的最大加速度，单位cm/s²，默认100。 |
| **0x23** | **起飞高度** | 0~1000 | 一键起飞设定的高度，单位cm，默认 100。 |
| **0x24** | **机器人半径** | 0~1000 | 障碍膨胀半径，单位cm，**默认 10 = 0.10 m**。建议设置为 = 机器人半径+10 |
| **0x25** | **规划模式** | **0~2** | 导航链路跑哪种规划：0=2D平面路径规划（例如地面移动小车）、1=3D自由空间路径规划（例如无人机）、2=3D沿地面空间路径规划（例如可爬楼梯机械狗，3D规划但要求轨迹贴合地面）。2D导航版模块仅支持模式0。默认0 |
| **0x26** | **小车运动学模型** | **0~1** | 0=全向，1=差速，默认0。仅在规划模式0生效 |
| **0x27** | **目标点容差**（小车模型） | 0~1000 | 到目标点多近算「到点」，单位cm，默认 15（= 0.15 m）。 |
| **0x28** | **最大偏航角速率**（小车模型） | 0~1000 | 单位**度/s**，默认 43（≈ 上游 0.75 rad/s） |
| **0x29** | **最小转弯半径**（小车模型） | 0~1000 | 单位cm，默认 100（= 1.0 m）。全向模型下不生效 |
| **0x99** | **模块类型** | **0~3** | **0=3D定位模块，1=3D导航模块，2=2D定位模块，3=2D导航模块** |

## 串口通信协议

波特率115200，8N1，需使能参数0x12。所有串口帧固定15字节：Byte 0为AA，Byte 14为0A，Byte 1为消息ID。帧中没有版本字节，主控与模块必须使用匹配的协议。

### 消息ID

| 消息 ID | 消息类型 | 方向 | 发送频率 | 说明 |
| --- | --- | --- | --- | --- |
| **0x01** | 当前位姿数据 | 模块 → 上位机 | 10Hz | 发布机器人在**图的原点系**里的位姿 (`base_init_map -> base_link`) |
| **0x02** | 导航目标点 | 上位机 → 模块 | 事件触发 | 下发期望目标点，模块收到后会**原封不动回发一次**作为应答 |
| **0x03** | 位置控制指令 | 模块 → 上位机 | 100Hz | 转发来自 `/drone_0_planning/pos_cmd` 的规划指令 |
| **0x04** | **实时速度** | 模块 → 上位机 | 100Hz | 转发 `/drone_0_planning/pos_cmd` 的速度与偏航角速率。线格式与 `0x01`~`0x03` 同（见下节），但第 `2~13` 字节的六格含义不同 |
| **0x05** | 飞控+重定位+规划+资源状态 | 模块 → 上位机 | 1Hz | 五件顺排在 `Byte 2`~`Byte 6`：飞控（五档，连接/解锁/着陆）、重定位、路径规划、**CPU 占用百分比**、**运存占用百分比**（后两格 `0`~`100`，`0xFF` = 未知）。**与 TCP 的 `AA 0B` 是同一套五件** |
| **0x00** | **命令帧** | 双向 | 事件触发 | `Byte 2` 是子命令号，**与 TCP `AA 00 <cmd> 0A` 的子命令号逐个相同**（通信测试 / 保存地图 / 读参数 / 保存参数 / 重启模块算法，**共五条**）。载荷空、补零到 15 字节，见下节「命令帧 / 参数帧格式」 |
| **0x10** | **参数帧** | 双向 | 事件触发 | `Byte 2` = 参数 ID、`Byte 3~4` = 值（大端 int16），**与 TCP `AA 10 <id> <vH> <vL> 0A` 同义**。主控发 = 改参数；模块发 = 读参数应答 / 保存参数回显。见下节 |

### 位姿、目标和位置指令

以下六个大端int16字段适用于0x01、0x02、0x03；0x04沿用帧结构，但物理量见速度表。位姿与目标以保存地图的图原点系base_init_map为准。发送目标时roll、pitch通常填0。

| 字节序号 | 名称 | 长度 | 说明 | 单位 | 备注 |
| --- | --- | --- | --- | --- | --- |
| **Byte 0** | 帧头 | 1 byte | 固定 `0xAA` | — | 起始标志 |
| **Byte 1** | 消息 ID | 1 byte | `0x01` / `0x02` / `0x03` / `0x04` | — | 数据类型标识 |
| **Byte 2~3** | X 高低字节 | 2 bytes | X 坐标 | **cm** | int16 |
| **Byte 4~5** | Y 高低字节 | 2 bytes | Y 坐标 | **cm** | int16 |
| **Byte 6~7** | Z 高低字节 | 2 bytes | Z 坐标 | **cm** | int16 |
| **Byte 8~9** | Roll 高低字节 | 2 bytes | 翻滚角 | **°（度）** | int16 |
| **Byte 10~11** | Pitch 高低字节 | 2 bytes | 俯仰角 | **°（度）** | int16 |
| **Byte 12~13** | Yaw 高低字节 | 2 bytes | 航向角 | **°（度）** | int16 |
| **Byte 14** | 帧尾 | 1 byte | 固定 `0x0A` | — | 结束标志 |

### 0x04速度帧

| 字节序号 | 名称 | 单位 | 说明 |
| --- | --- | --- | --- |
| **Byte 2~3** | vx 高低字节 | **cm/s** | 机体/图坐标系线速度 x（`velocity.x * 100`，int16，大端） |
| **Byte 4~5** | vy 高低字节 | **cm/s** | 线速度 y |
| **Byte 6~7** | vz 高低字节 | **cm/s** | 线速度 z |
| **Byte 8~9** | 恒 `0` | — | 滚转角速率**无数据源**，固定补零 |
| **Byte 10~11** | 恒 `0` | — | 俯仰角速率**无数据源**，固定补零 |
| **Byte 12~13** | yaw_dot 高低字节 | **°（度）/s** | 偏航角速率（`yaw_dot * 180 / π`，int16，大端；按本仓既有口径**截断**取整） |

### 0x05状态帧

| 字节序号 | 名称 | 长度 | 说明 | 备注 |
| --- | --- | --- | --- | --- |
| **Byte 0** | 帧头 | 1 byte | 固定 `0xAA` | 起始标志 |
| **Byte 1** | 消息 ID | 1 byte | 固定 `0x05` | 状态帧标识 |
| **Byte 2** | **飞控状态枚举** | 1 byte | 详细定义见下表 | 取值范围 `0x00` ~ `0x04` |
| **Byte 3** | **重定位状态** | 1 byte | `0`进行中、`1`成功、`2`失败、`3`未响应 | 取值 `0`/`1`/`2`/`3` |
| **Byte 4** | **规划状态** | 1 byte | 取值同 `Byte 3` | 取值 `0`/`1`/`2`/`3` |
| **Byte 5** | **CPU 占用百分比** | 1 byte | 整块板子的聚合 CPU 利用率 | `0`~`100`；**`0xFF` = 未知** |
| **Byte 6** | **运存占用百分比** | 1 byte | `(MemTotal−MemAvailable)/MemTotal`，不含 swap | `0`~`100`；**`0xFF` = 未知** |
| **Byte 7~13**| 预留字段 | 7 bytes | 补零 (`0x00`) | 保持 15 字节帧长对齐 |
| **Byte 14** | 帧尾 | 1 byte | 固定 `0x0A` | 结束标志 |

重定位和规划均为0进行中、1成功、2失败、3未响应。CPU/运存为0~100的百分比，FF表示未知；不能当作255%或0%。

飞控状态枚举：

| 枚举值 | 状态名称 | 含义说明 | 底层建议处理逻辑 (STM32) |
| --- | --- | --- | --- |
| `0x00` | **未连接/通信丢失** | ROS模块与飞控断连，或底层超 2 秒未收到心跳 | 🔴 **拦截目标点发送**，触发安全保护 / 熄灭指示灯 |
| `0x01` | **未解锁 (Unarmed)** | 飞控通讯正常，在地面处于安全加锁状态 | 🔴 **拦截目标点发送**，指示灯慢闪提示 |
| `0x02` | **已解锁，地面待命** | 电机已转动，但仍未起飞离开地面 | 🔴 **拦截目标点发送**，指示灯快闪警告 |
| `0x03` | **空中悬停 (Hovering)** | 飞机已起飞，处于定点等模式等待指令 | 🟢 **允许下发目标点**，指示灯常亮 |
| `0x04` | **执行航点 (Offboard)** | 飞机在空中，正在自动飞往规划器给出的目标点 | 🟢 **允许下发目标点**，指示灯常亮 |

### 命令和参数帧

```text
命令帧  AA 00 <cmd> 00×11 0A
参数帧  AA 10 <id> <vH> <vL> 00×9 0A
```

| cmd | 操作 | 应答 |
| --- | --- | --- |
| 01 | 通信测试 | 原样回显15字节帧 |
| 02 | 保存地图 | 产物核对通过才回显；定位模式拒绝，失败或拒绝均不回显 |
| 03 | 读取参数 | 返回22条参数帧，按参数ID解析 |
| 04 | 保存参数 | 返回22条参数帧和本条命令回显 |
| 06 | 重启算法 | 先回显后执行；回显只确认收到请求，仍需等待重连 |

没有串口05地图下载命令，下载地图需用网络。参数帧的值为大端有符号int16；写参数不回帧，需保存并读回核对。命令和参数不可按15字节位姿帧中的六个物理量解析。

不同目标发布间隔至少1s，目标原样回显只表示模块收到帧，不代表已发布给规划器、规划成功或到达。0x03、0x04依赖规划输出。2D串口目标Z会替换为0x23起飞高度，2D位姿Z来自飞控，需独立确认定高数据持续有效。
